### iPhone-/Mobile-Ansicht mit Auto-Erkennung (`html/m/`, 2026-06-20)
Schlanke, touch-optimierte SPA fürs iPhone unter **`/m/`** — **kein eigener Port/Container**, läuft über den bestehenden `dashboard`-Container (Port 80) und damit über **`https://dashboard.intranet.yourdomain.example/m/`** (Caddy-HTTPS). Nutzt **dieselbe API** (FastAPI 8798) wie das Desktop-Dashboard.
- **Zugang = automatisch:** Die Desktop-`index.html` enthält ganz oben im `<head>` ein **synchrones** Inline-Script, das iPhones (UA `iPhone|iPod` oder `Android Mobile`, bzw. Touch + Viewport ≤768px) per `location.replace('/m/')` umleitet — läuft VOR allen anderen Scripts → kein Aufblitzen der Desktop-Seite. **Opt-out:** `?desktop=1` setzt `localStorage.force_desktop` (Desktop dauerhaft erzwungen), `?mobile=1` hebt es auf. Auf `/m/` läuft das Snippet nicht → keine Schleife. In der Mobile-Topbar ein **🖥-Link** (`/?desktop=1`) zurück zur Desktop-Version. So gibt es **eine** URL für alle Geräte.
- **Frontend:** `html/m/index.html` + `html/m/m.css` + `html/m/m.js` (self-contained, **kein** `api.js` nötig, alle Pfade relativ über nginx). Dark-Theme passend zum Desktop, Touch-Targets ≥44px, `viewport-fit=cover` + `env(safe-area-inset-*)` für Notch/Home-Indicator, Font ≥16px (kein iOS-Auto-Zoom in Inputs). 3 Views: **Übersicht** (Kategorie-Chips + Suche + Projektkacheln aus `GET /api/dashboard`, Badges 📥/⚙️/✅/📂/📎), **Board-Detail** (s.u.), **Schnell-Erfassung** als Bottom-Sheets: 💡 Idee (`POST /boards {name,description}`) + 📷 Foto (`POST /project-from-photo`, Client-Kompression 1200px/0.82 + optional GPS, exakt wie `foto.html`). Untere Tabbar: Projekte/Idee/Foto.
- **Board-Detail = Segment-Umschalter „📋 Liste / ⌨️ Terminal"** (`#board-seg`, `setBoardMode`):
  - **Direktlink-Chips (`#board-links`, 2026-06-23):** unter der Segment-Leiste eine horizontal scrollbare Chip-Reihe mit denselben Sprungzielen wie der Desktop-Kopf (🌐 Web-App, 📁 Dateien, **🗂 Daten** = `data/`-Ordner, 📄 Doku, 🐙 GitHub) — Quelle `GET /api/project-links?id=` (`renderBoardLinks` in `m.js`, `BOARD_LINK_DEFS`), nicht ermittelbare Ziele werden ausgeblendet (`.board-links:empty{display:none}`). Grund: im Browser-Terminal sind Pfade nicht klickbar → am Handy ein Tap zum FileBrowser/`data/`. Best-effort (Fehler blockieren das Board nie).
