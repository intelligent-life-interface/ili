## Versionsverantwortung und Audit-Trail

Die aktuelle Fassung dieses Disclaimers ist über die Git-History nachverfolgbar. Jede Änderung dokumentiert sich durch Commit-Hash und Änderungsdatum.

Nutzer können die genaue Fassung ihrer Installation überprüfen:

```bash
# Prüfe den letzten Commit für diese Datei
git log -1 --oneline DISCLAIMER.md

# Schaue die exakte Fassung zu einem bestimmten Commit an
git show <commit-hash>:DISCLAIMER.md
```

Dies ermöglicht ein **Audit-Trail für Nutzer**: Sie können jederzeit nachvollziehen,
welche Version des Disclaimers mit ihrer Installation mitgeliefert wurde (Commit-Hash + Änderungsdatum).
